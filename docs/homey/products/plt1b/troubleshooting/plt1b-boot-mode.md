# Putting The PLT-1B In Boot Mode

!!! info "This will cover how to put the PLT-1B into boot mode."

    This is needed to force the device into boot mode to reflash the firmware.

![PLT-1B diagram labeling the reset button on the left and the boot button and USB-C port on the right](/assets/plt-1b-buttons-2.png)

## Method 1: Boot Button Only

1\. Position the PLT-1B as shown in the image below and locate the small opening to press the boot button.

![Open PLT-1B case with a tool pointing to the boot button on the PCB near the USB-C port](/assets/plt-boot-mode-pic-2.jpg)

![Tool inserted into the boot button opening on the side of the closed PLT-1B case](/assets/plt-boot-mode-pic-4.jpg)

2\. Use a pin to press and hold the boot button, while holding the boot button plug the PLT-1B back into your computer/power and then release the boot button

3\. Continue with [uploading the firmware](https://wiki.apolloautomation.com/homey/products/plt1b/troubleshooting/plt1b-code/)

## Method 2: Boot and Reset Buttons

1\. Plug in the device

2\. Press and hold the boot button, while holding it press and release the reset button, then release the boot button

![Tool pointing to the reset button on the PLT-1B PCB](/assets/plt-boot-mode-pic-6.jpg)

![Tool pointing to the reset button opening on the end of the closed PLT-1B case](/assets/plt-boot-mode-pic-7.jpg)

3\. Continue with [uploading the firmware](https://wiki.apolloautomation.com/homey/products/plt1b/troubleshooting/plt1b-code/)
