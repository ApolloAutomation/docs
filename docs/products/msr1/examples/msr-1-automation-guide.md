# MSR-1 automation guide

A full automation walkthrough for the Apollo MSR-1 isn't on this page yet. In the meantime, these guides show you how to put your MSR-1 to work in Home Assistant:

- [MSR-1 and Alarmo home security](../msr1-alarmo/): build a fully local security system from MSR-1 sensors and Alarmo, installed through HACS, that you arm and disarm from your dashboard.
- [Using the MSR-1 buzzer](../using-msr-1-buzzer/): play a tune on the buzzer from Home Assistant, then reuse the same action in an automation.
- [MSR-1 examples from GitHub](../msr-1-examples-from-github/): example MSR-1 configurations and automations published in the Apollo GitHub repository.
