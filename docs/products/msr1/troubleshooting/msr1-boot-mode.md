# Putting The MSR-1 In Boot Mode

!!! info "This will cover how to put the MSR-1 into boot mode."

    This is needed to force the device into boot mode to reflash the firmware.

## Method 1: Boot Button Only

You'll hold the boot button while you plug in the USB-C cable.

1\. Position the MSR-1 as shown in the image below and locate the small opening to press the boot button (the left button).

![MSR-1 case with the boot button opening highlighted in red among the top vents](/assets/msr-1-top-shot-boot-button.jpg)

2\. Push and hold the boot button. While still holding the button down, plug in a USB-C cable into the USB-C port of your MSR-1 then let go of the button.

3\. Continue with <a href="https://wiki.apolloautomation.com/products/msr1/troubleshooting/msr1-code/" target="_blank" rel="noreferrer nofollow noopener">uploading the firmware document</a>.

## Method 2: Boot and Reset Buttons

You'll use the boot and reset buttons together while the device is plugged into your computer.

1\. Unplug the device and locate the boot and reset buttons as shown in the image below.

2\. Plug it into your computer.

3\. Hold down the boot button (the left button), then press and release the reset button (the right button) while keeping the boot button pressed. Finally, release the boot button.

![Bare MSR-1 board with arrows marking the Boot and Reset buttons along the top edge](/assets/msr-1-buttons.jpg)

4\. Continue with <a href="https://wiki.apolloautomation.com/products/msr1/troubleshooting/msr1-code/" target="_blank" rel="noreferrer nofollow noopener">uploading the firmware document</a>.
