# Putting The TEMP-1 In Boot Mode

!!! info "This will cover how to put the TEMP-1 into boot mode."

    This is needed to force the device into boot mode to reflash the firmware.

## Method 1: Boot Button Only

You can put your device into boot mode with only the boot button and a paperclip.

1\. Position the TEMP-1 so that the USB-C port is facing you. On the right side of the device, locate a small opening where you can use a paperclip to press the boot button.

![Side of the TEMP-1 case with a tool pointing into the small opening for the boot button](/assets/temp-1-boot-button-side-view.jpg)

If you prefer, please remove the lid by gently prying up on the small slit by the top of the case.

![Metal tool prying the lid off the TEMP-1 case at the slit near the top](/assets/temp-1-pry-open.jpg)

![TEMP-1 with the lid removed and a tool pointing at the BOOT button next to the buzzer](/assets/temp-1b-boot-button-lid-off.jpg)

2\. Push and hold the boot button. While still holding the button down, plug in a USB-C cable into the USB-C port of your TEMP-1 then let go of the button.

3\. Continue with [uploading the firmware document](https://wiki.apolloautomation.com/products/temp1/troubleshooting/temp1-code/).

## Method 2: Boot and Reset Buttons

You can also open the case and use the boot and reset buttons together to put your device into boot mode.

1\. Unplug the device and remove the case as shown in the images above

2\. Plug it into your computer.

3\. Hold down the boot button (shown above), then press and release the reset button (shown below) while keeping the boot button pressed. Finally, release the boot button.

![TEMP-1 with the lid removed and a tool pointing at the RST reset button](/assets/temp-1-reset-button-lid-off.jpg)

4\. Continue with [uploading the firmware document](https://wiki.apolloautomation.com/products/temp1/troubleshooting/temp1-code/).
